# AI tools used

I mainly used two AI tools for this project.

From my previous projects I have learned that before writing any code, you should have your whole
project documented in one file, like `PRODUCT.md`. It holds the complete details: what the problem
is, which architecture to use, and a complete phase-wise development plan. That single file should
be enough to reproduce the entire application.

**1. Perplexity**
I used Perplexity for research: finding similar systems and deciding on the tradeoffs while writing
`PRODUCT.md`. The main reason I used it is that it is very good at searching the web and referring
to documentation while generating an answer, so its answers are based on facts.

**2. Claude Code**
I used Claude Code for the coding. It did almost all of the coding work, while my role was to review
it and guide it using the `PRODUCT.md` file.
